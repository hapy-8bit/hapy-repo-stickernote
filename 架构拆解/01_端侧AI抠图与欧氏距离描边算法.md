# 端侧AI抠图与欧氏距离描边算法

关联：[[00_每日贴纸_全景图谱|全景图谱]] · [[Documentation/MEDIA|媒体处理合同]] · [[Documentation/PRODUCT_PLAN|产品基线]]

## 1. 核心流程与类结构
- `StickerPhotoDecoder`：图片输入统一限制最长边 <= 1280px，SDR RGBA 解码，通过 `readPixelsToBuffer` 保持完整颜色空间与色彩准确性。
- `CoreVisionKit` (`subjectSegmentation`)：端侧离线主体检测，请求最多 6 个候选主体，获取逐像素 0..255 蒙版。
- `StickerSubjectMask`：合并多候选蒙版或提取单个主体候选，处理边界合法性。
- `StickerRaster`：核心像素计算，包含一维欧氏距离变换与圆润轮廓生成。
- `StickerRenderTask`：基于 `@Concurrent` 在 `TaskPool` 线程池并发执行，避免阻塞 UI 线程。

## 2. 欧氏距离变换白边算法
传统图像膨胀算法（Dilation）会产生方形尖角与毛刺。本项目采用两遍一维平方欧氏距离变换（Squared Euclidean Distance Transform）：
1. 横向与纵向两遍抛物线包络线性时间扫描，计算每个背景像素到主体边缘的最短欧氏距离。
2. 轮廓仅向主体外侧（透明区）扩展，**严格不覆盖主体非零 alpha 区域**。
3. 主体自身的色彩（RGB）与半透明柔和边缘独立保留，不受白边宽度变化干扰。
4. 弱噪点阈值保护（>= 128 种子点），防止孤立噪点形成不透明白色色块。

## 3. 降级保护
- 系统无 AI 能力、模型正忙或无法检测到清晰主体时，自动降级为“保留完整照片”模式，并向用户提示。
- 允许用户在原图模式下继续执行直角旋转、比例裁切与加框，保证编辑链路不中断。
