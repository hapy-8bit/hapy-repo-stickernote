# 动画代次保护与减少动态无障碍

关联：[[00_每日贴纸_全景图谱|全景图谱]] · [[Documentation/DEVELOPMENT|开发基线]] · [[Documentation/UI_DESIGN|奶油手帐设计合同]]

## 1. PageMotion 代次锁机制
在 ArkUI 单页面多状态（State-driven routing）架构下，连续快速的点击可能导致多个动画回调互相穿插。
- `PageMotion` 内部维护单调递增的 `generation`（代次标识）。
- 每次发起新动画时递增 `generation` 并锁定输入。
- 在 `onFinish` 回调触发时，严格校验回调携带的代次是否与当前最新代次相符；若已过时则直接丢弃，防止陈旧动画解锁错误的新路由状态。

## 2. 相机与草稿退场特例
普通页面采用 100ms 淡出 + 190ms 入场及 14vp 方向位移。但对于相机与制作草稿退出：
- `PageMotion.enter` 采用“立即提交路由，仅淡入新页面”策略。
- 保证相机的 XComponent Surface 和原生硬件连接能够被瞬时卸载，不因退出过渡动画延长硬件资源占用。
- 制作放弃退出时，草稿文件被即时释放，不给用户呈现老预览闪烁。

## 3. 减少动态（Reduced Motion）无障碍适配
- `MotionPreferences.reduced()` 动态检测系统无障碍减少动态开关（支持 API 23+ 系统能力，向下兼容 API 13）。
- 开启后，所有过渡动画直接跳过耗时曲线，同步提交视图与位置，避免动态敏感人群产生眩晕感。
