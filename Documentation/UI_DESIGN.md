# 每日贴纸 UI 合同 · 奶油手帐

用户已选择 A「奶油手帐」。本文是当前实现的页面规范，历史备选见 `UI_DESIGN_PROPOSALS.md`。验证结果以 `BUILD_RECEIPT.json` 与 `DEVICE.md` 为准。

## 视觉定位

打开一页生活手帐：奶油背景承托一张温暖纸页，深棕文字建立阅读层级，真实照片贴纸成为纸面主体。使用系统中文字体与原生 SymbolGlyph，不引入未确认授权的品牌字体。

| 元素 | 统一规则 |
| --- | --- |
| 颜色 | 背景 `#F6F3EB`，纸面 `#FFFDF8`，墨色 `#332F29`，辅助字 `#827C73`，细线 `#E8E3D9`，浅底 `#ECE7DC`，点色 `#BA6245` |
| 字号 | 品牌 30 Bold，二级标题 22 Bold，空态标题 18 Bold，分节 16 Medium，正文/按钮 14，说明 12 |
| 间距 | 4/8/12/16/20/24/32；主要内容左右 20，首页外纸面 18；标题、正文和动作按各自内容边线对齐 |
| 容器 | 主要纸面圆角 30，工具纸面 24，输入和选项 14；避免同一分组反复套白卡 |
| 按钮 | 普通触摸高度至少 44，主提交至少 48；主操作深墨胶囊、次操作浅底胶囊、轻动作透明；选项用浅底和细边表示选中 |
| 图标 | 主要 20，次要 16；图标点击区 44；空态图形使用单一轮廓容器，禁止混入 emoji |
| 装饰 | 首页纸页使用淡横线；轮廓虚线只服务空态；阴影仅少量用于悬浮操作，不叠加厚卡片 |

默认浅色外观。纸色偏好仍支持暖白、奶油、浅草；它只改变纸色关系，不改变标题、圆角、按钮与导航合同。

## 三种页面结构

### 品牌首页与贴纸盒

- 首页：品牌与真实累计计数 → 月份/月历/设置 → 所选日期当周七日条 → 独立横线纸页 → 固定底栏。
- 七日条周一开始，允许跨月跨年；选中日用纸色竖胶囊和粗字，今天用陶橙提示，有记录用真实摆放标记。月历沿用同一状态语义。
- 首页累计数取独立资产数量，纸页当日数量取该日摆放数量；反复使用同一贴纸不会伪增资产数。
- 纸面无记录时显示「这一天还没有贴纸」及轻量说明。空态不放另一颗抢占中心的主按钮，主要添加入口稳定在底栏。
- 底栏为「手帐／加号／贴纸盒」，与页面背景连续。中央宽胶囊加号打开拍照、相册、已有贴纸三种来源；月历在日期区域进入。
- 贴纸盒沿用品牌页头尺度、轻搜索与分类筛选；一张大纸面承托整个收藏区域。真实网格中的照片、名字与动作使用留白和细线组织。
- 首页与贴纸盒保持挂载，保留搜索、筛选和滚动；隐藏内容不能接收输入或无障碍焦点。

### 二级纸页

- 设置、分类管理、月历和协议使用统一返回栏、22 粗标题、20 边距和同一种纸卡/细线。
- 设置将偏好、管理、联系和关于收纳为轻分组，保留真实存储统计与协议入口。
- 月历依据真实摆放显示缩略图或标记；无记录日不显示虚构图片。
- 分类中的新增、编辑和排序仍遵守原有数据约束，视觉调整不改变删除与保存规则。

### 制作与拍摄

- 制作页：统一返回栏 → 245 高圆角结果预览 → 一张工具纸面 → 固定底部保存动作。
- 工具纸面分「图像／白边／信息」三个下划线页签。图像内保留主体、原图、方向与裁切；方向裁切按需展开。
- 信息草稿由制作页面持有，切换工具不能清空输入；重拍和提交继续交给原有回调。禁用与处理失败状态以实际会话为准。
- 纸面/棋盘格只用来检查透明边缘，不参与成品像素。原图降级和 legacy 限制必须清楚显示。
- 拍摄保持功能性深色取景，外框、触摸区与按钮沿用奶油手帐规范。构图线轻量化，真实 Surface 与相机资源生命周期不因装饰变化。

## 状态与实现边界

- 空、加载、错误、处理、禁用、选中各有真实状态；不得用样例记录填充纸面或收藏区。
- 图片落盘、仓库提交、取消清理、不可变历史版本与私有路径规则不变。
- 纸面编辑工具覆盖画布，进入编辑不改变坐标区域；归一化位置按实际纸面尺寸显示。
- 新增来源弹层使用 API 13 可用的原生半模态接口；弹层关闭后才交接相机或照片选择器。
- 页面/组件严格少于 800 行。`Theme` 保存令牌，`PaperStyles` 保存共享属性，页面组件持有状态与回调。
- 构建和空态模拟器检查不能代替真实照片、触摸摆放、大字号与 API 13 设备验收。
