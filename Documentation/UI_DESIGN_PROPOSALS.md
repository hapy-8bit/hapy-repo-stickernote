## 选择前的 UI 定位与问题

选择前的实现是「暖纸配色的工具界面」：首页使用整页画布，贴纸盒使用素材网格，制作页使用纵向工具表单，设置使用分组白卡，相机另用虚线与大圆角装饰。

当时的 `Theme.ets` 与 `PaperStyles.ets` 仅统一部分颜色、字号、按钮高度和圆角，未定义页面构图、纸面层级、导航形态、装饰用途与空态母版，因此控件相似但整体风格不一致。

## 用户参考的设计意图

参考图的主要特征是奶油背景、深棕文字、圆润粗品牌标题、轻量真实计数、七日日期条、大面积圆角横线纸、居中空态和克制的底部导航。重点是「打开一页生活手帐」的整体感受。

- 品牌沿用「每日贴纸」，不复制参考品牌名。
- 首页保留清晰的品牌、日期和纸面三个层次；纸张占据主体空间。
- 顶部累计贴纸数与纸面当日数量分别取真实数据。没有记录时都显示 0，不照搬参考数值。
- 导航提案为「今日／手帐、加号、贴纸盒」；月历由日期区域进入。参考截图右侧的日历入口不自动替换现有贴纸盒。
- 加号表达「添加贴纸」，提供拍摄、相册或已有贴纸；A 方案已实现此入口。
- 选择前的产品合同曾移除品牌大标题和七日条；当前 [PRODUCT_PLAN.md](PRODUCT_PLAN.md) 已按 A 方案同步品牌、七日条与导航规则。

## 三套方案共同遵守的规则

1. 固定三个页面类型：品牌首页、二级纸页、沉浸任务页。二级页共享返回栏，相机允许功能性反色，但沿用同一套间距、图标和动作语义。
2. 统一背景、内容纸和控件三层关系；每页一个主要视觉承载层，A／B 用纸面表达，C 可通过留白表达，避免为了分组不断增加卡片。
3. 间距使用 4／8／12／16／20／24／32 标尺，主要内容边距按样式在 20–24 之间选择，A 外纸面可到 18；同一层级的页头、正文和动作区对齐。
4. 主动作使用深墨实底，B 使用橄榄实底，次动作浅底；筛选和制作选项降低视觉重量，App 落地时触摸范围至少 44。禁用、加载、选中和错误状态统一定义。
5. 统一原生线性图标，选中时按统一规则填充或变色；不混入 emoji。阴影只用于确需悬浮的控件，纹理与虚线各有固定用途。
6. 空态统一图形尺度、标题层级和说明位置。无贴纸就是空；制作页无图片时显示空预览，不生成样例照片、抠图结果、历史记录或会员状态。
7. 日期分别定义今天、选中、有记录三种状态，首页和月历共用；真实累计数量、当日数量与月度天数不得混淆。
8. 纸色偏好只替换纸面相关颜色，不能导致页面各用一套字号、按钮和导航。短注记、异常、原图降级说明仍需清晰可读。
9. 上述字号是视觉层级提案，落地时需验证系统字体缩放和窄屏。具体字体须确认资源可用性与授权后再选定，不预先承诺某款字体。
10. 选定后先定颜色、字体、间距、容器、导航和状态合同，再让首页、贴纸盒、制作、设置、相机与月历一起遵守；视觉验收不能只检查空首页。

**A · 奶油手帐** 最贴近本次参考，也能让真实贴纸自然成为纸面主体。当前已将圆润程度、七日条和大纸卡确立为共同基线，并按素材管理、制作与设置的功能密度适配。
