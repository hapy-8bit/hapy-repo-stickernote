# 每日贴纸隐私政策

版本：2026-09-29.1
更新及生效日期：2026年9月29日
开发者：lh
联系邮箱：hapy8bit@163.com

一、适用范围

本政策适用于每日贴纸（com.lh.stickernote）当前本地使用版本。我们希望你通过拍摄或选取照片制作贴纸，再收藏和放入日期纸面。请在使用前阅读本政策及用户服务协议。

二、照片与相机

仅在你点击拍照后，应用申请并使用相机权限，用于取景和拍摄照片；退出拍摄或进入后台时释放相机。纯拍照不申请麦克风权限。拒绝相机权限不会删除已有贴纸，你仍可浏览已有内容或使用系统照片选择器。

相册导入使用系统照片选择器，只取得你主动选择的图片。应用不要求读取整个相册。临时图片会被复制到应用私有目录，以便重启后继续编辑和查看。

三、主体分割与图像处理

应用使用鸿蒙系统 Core Vision 主体分割能力生成蒙版，再在本机裁切、加白边和生成贴纸。当前应用代码不向开发者服务器或云端 AI 服务上传照片、蒙版、标题或备注。系统视觉能力的可用性、模型初始化和系统网络行为由华为系统服务决定，受系统相关规则约束。

分割结果可能不完整或有边缘误差。你可选择其他主体、重拍、保留原图或使用裁切。当前版本没有云端识别命名、账号登录、广告、支付、运营者统计或应用自建云同步。

四、本机保存的数据

应用在私有目录保存你确认留下的源图、主体蒙版和贴纸成品，以及标题、分类、收藏状态、日期、短注记、摆放位置和制作版本；另保存纸色、启动偏好和协议接受版本。当前列表使用成品 PNG 展示缩略预览，不另建独立缩略缓存文件。制作新版本不自动覆盖其他日期已引用的历史版本。

取消制作时，应用只清理本次草稿文件。正常保存时，先写入图片再提交记录；发生错误时保留原有有效数据。错误提示不包含你的照片或完整短注记。

五、保存期限与删除

上述内容保存在当前设备，直到你主动删除、清除应用数据或卸载。移除某一天的摆放不会自动删除贴纸资产；永久删除资产前会检查日期引用，仍被使用时需先移除对应摆放。确认永久删除后清理该资产的原图和制作版本。应用不建立自有服务器备份。本机保存不能保证换机或卸载恢复，系统备份是否覆盖相关内容由系统决定。

你可以在贴纸盒查看、更改分类或标题、重新制作或删除资产，在日期纸面修改或移除摆放，并在系统设置撤回相机权限。未来提供导出、备份或联网能力时，将按实际功能另行告知，不视为本政策已经启用这些功能。

六、安全与反馈

我们使用应用沙盒、系统权限和必要的文件校验保护数据。本机私有目录不等于独立加密保险库，设备损坏、系统问题或误删仍可能导致数据丢失。请保护设备锁屏和系统账户。

当你通过邮件反馈时，我们仅处理你主动提供的联系方式、问题描述和排障材料。请不要发送密码、验证码、身份证件或不必要的私人照片。确需样本时，请先自行遮盖敏感信息。

七、未成年人

未成年人应在监护人指导下拍摄和使用，避免记录或公开他人敏感内容。我们不主动采集年龄或建立儿童个人资料。

八、政策更新与联系

功能或数据处理方式发生重大变化时，我们会更新政策并在应用中说明；需要重新同意的处理将在你同意后启用。对信息处理、数据更正或删除有疑问，可联系开发者 lh：hapy8bit@163.com。处理请求时只核验解决问题必要的信息。
